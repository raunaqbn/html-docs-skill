# Storyboard spine

Use one sentence as the persistent worked example. Tokens begin as stations.
The learner then watches:

1. one token emit a query;
2. every token expose a key and value;
3. query-key similarity become a normalized routing distribution;
4. routed values combine into the next representation;
5. multiple heads repeat the mechanism in parallel spaces;
6. a causal mask close routes to future tokens.

Build the equation beside the diagram one term at a time. Never show the
finished equation before the phrase that introduces its final operation.
