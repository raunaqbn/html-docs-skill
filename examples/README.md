# Reproducible launch examples

Each example begins with a different source type and ends with portable HTML
Docs artifacts. The lightweight bundles committed here contain the production
brief, evidence manifest, storyboard, project manifest, and reproduction
prompt. Narration masters and rendered media are hosted by the
[HTML Docs showcase](https://www.html-docs.com/showcase) so the repository stays
small.

- [`deterministic-html-video-course`](./deterministic-html-video-course) —
  codebase → course
- [`browser-rendering-pipeline`](./browser-rendering-pipeline) — website →
  document + video
- [`attention-routing-course`](./attention-routing-course) — research topic →
  course

All three use the open Producer. The active Codex or Claude session performs
research and authors the artifacts; the CLI does not call a hidden model.
