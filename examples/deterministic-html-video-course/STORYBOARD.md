# Storyboard spine

1. **The problem:** wall-clock animation and guessed narration timing drift.
2. **The contract:** a composition is a pure function of explicit time and variables.
3. **The audio clock:** final word timing owns cues, captions, scenes, and chapters.
4. **The render path:** seek, settle, capture, encode, and resume from cached chunks.
5. **The delivery path:** live HTML first, immutable MP4 fallback.
6. **The refinement loop:** select a semantic target, inspect evidence, commit a new version.

The framing rhythm rotates among a causal pipeline, track timeline, browser
cross-section, system architecture, and Guided Studio workspace.
