# Provenance

HTML Docs' course, video, Player, and Guided Studio implementations are authored
for this repository and use the portable HTML Docs project formats described in
the skill.

The deterministic renderer originated in the HTML Docs application repository
and was transferred here by its owner so this repository is the canonical
public implementation. New changes should land here first and be consumed by
the hosted application through released packages.

Before a release:

1. Scan source, documentation, fixtures, generated examples, and package
   metadata for prohibited product names and obsolete artifacts.
2. Run dependency license and secret scans.
3. Verify every included showcase asset was generated by HTML Docs or has a
   recorded compatible license.
4. Verify provider credentials and private source snapshots are absent.
5. Preserve all required notices for material that remains.

Git history is retained. Current distributed trees must contain only the
implementation and attributions they actually require.
