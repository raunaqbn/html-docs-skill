# Showcase application

The production showcase is served by the HTML Docs web application at
[html-docs.com/showcase](https://www.html-docs.com/showcase). It embeds live
deterministic Player instances, rendered fallback excerpts, artifact strips,
and reproducible source bundles from [`examples/`](../examples).

Animated README media is externally deployable and intentionally lightweight.
The Git repository keeps only short GIF excerpts and source manifests; full
narration masters, MP4s, and version bundles live with their hosted projects.

## Featured courses

- [Robot Learning, Gently](https://www.html-docs.com/courses/42078fdc-ed98-474a-907b-5322346dbf61) — a 12-lesson bridge from robot-learning fundamentals to an ANIMA-Kiwi capstone.
- [Build an LLM from First Principles](https://www.html-docs.com/courses/dda6b2c1-b6e5-4d35-b79b-9a6531b2260b) — an 11-lesson, build-first path from scalar autodiff to a trained and evaluated decoder-only Transformer.
- [The Inference Company Founder’s Field Course](https://www.html-docs.com/courses/300c8242-3c75-4d2d-a406-9f0b93c8bd6d) — a seven-lesson operating course spanning startup wedge, serving MVP, benchmarks, unit economics, production operations, and hardware gates.
